# 주재륜

**데이터·AI 엔지니어**

## 소개

블록체인 시스템 개발 경험을 바탕으로,
데이터와 AI 엔지니어링으로 역량을 확장하고 있습니다.

- 성균관대학교 소프트웨어학과 (2018.03 – 2027.02 졸업예정)
- 이큐비알홀딩스 블록체인 연구원 (2021.01 – 2022.12) | Go 기반 코어 전환, 조회 계층 분리, 노드 환경 자동화
- Microsoft Data School (2026.03 – 2026.09) | Azure 기반 데이터·AI 프로젝트 수행

## 기술 스택
- 언어: Python, SQL, Go, TypeScript, JavaScript, C/C++
- 데이터: PySpark, Databricks, Microsoft Fabric, PostgreSQL, MongoDB
- 웹: Next.js, React, NestJS, FastAPI
- AI: Azure OpenAI, Azure AI Search, RAG
- 인프라: Azure, Docker, Bicep, GitHub Actions, Grafana
